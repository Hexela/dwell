# Security policy

Dwell is not yet released. Security reports are nevertheless welcome, especially where the architecture or protocol design could permit unauthorised device control, sensitive-data exposure, privilege escalation, or permission bypass.

Please do not disclose suspected vulnerabilities in a public GitHub issue.

Until a dedicated security reporting address is published, contact the project owner privately through the GitHub account listed for the repository. Do not include live credentials, private keys, precise household location, or unredacted diagnostic data in an initial report.

The supported-version matrix and coordinated-disclosure process will be published before the first public binary release.
